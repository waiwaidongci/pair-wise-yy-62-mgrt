# pair-wise-yy-62 多用途船舶配载方案校核与航次审阅平台

支持集装箱、散货和重大件配载，提供三维货位查看、二维剖面、拖拽换位、重心与稳性计算、危险品隔离、绑扎冲突、方案对比和可打印配载图。

## 冷藏箱开航校核

- 冷藏箱、货位与供电回路联动建模；剩余功率按**已分配（占用插座）箱数**逐箱扣减，不再把余量不足的插座当可用。
- 冷藏箱未接入供电或回路超限时列为开航阻断项，并给出同回路有余量、距当前 Bay 最近的**替代货位/插座**。
- 两名值班员同时提交同一插座时按确认顺序仲裁：**先确认者保持占用，后到者看到冲突**且不扣减功率。
- 货位移动或回路容量变化后，隔离、稳性与供电结论**立即失效**；复核完成前禁止锁定与打印。
- 断网时确认仅入缓存；回连后**按插座合并**，逐插座只接受先确认的一笔，重复上传不重复扣减。
- 缺少回路数据的旧稿在载入时自动**升级为首版**（补全回路/插座、作废旧复核结论）。

## 技术栈

React、Mantine、Redux Toolkit、React Router、RTK Query、Three.js、Vite、TypeScript。
